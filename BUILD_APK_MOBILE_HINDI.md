FIGHTER FTR APP - Mobile se APK banane ka shortcut

1. Is ZIP ko GitHub par ek nayi repository mein upload karein.
2. Repository ke Actions tab mein "Build FIGHTER FTR APP APK" workflow kholein.
3. "Run workflow" dabayein (ya main branch mein push ke baad build apne-aap chalega).
4. Build green/success ho jaaye to run kholein, neeche Artifacts mein FIGHTER-FTR-APP-debug-apk download karein.
5. Download ki ZIP ko phone par extract karein. app-debug.apk install karein; zarurat ho to Android Settings mein browser/files app ke liye "Install unknown apps" allow karein.

Note: GitHub par project upload karna aur workflow run karna zaroori hai. Yeh debug APK hai. App abhi demo hai; login/online chat/photo/voice/status real backend se connected nahi hain.
